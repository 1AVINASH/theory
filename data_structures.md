## Bloom filters
* A Bloom filter is a space-efficient, probabilistic data structure used to test whether an element is likely a member of a set. 
* It uses a bit array and multiple hash functions to determine if an element might be in the set. 
* While Bloom filters can quickly determine if an element might be in the set, they can also produce false positives, meaning they might incorrectly indicate an element is present when it is not. However, they are very memory-efficient and can be used in various applications like databases, caching, and network applications.

## B Trees
* A B-tree is a self-balancing tree data structure used in databases and filesystems to store sorted data and allow logarithmic time for insertions, deletions, and lookups.


## Min Heap
* Min Heap is a type of complete binary tree data structure where the value of each parent node is less than or equal to the values of its children nodes.This property ensures that the root node always contains the smallest value in the entire heap.
