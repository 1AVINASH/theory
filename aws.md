## Glue
* AWS Glue is a serverless data integration service that simplifies data discovery, preparation, and loading for analytics, machine learning, and application development
* AWS Glue supports ETL workflows, allowing you to extract data from various sources, transform it to the desired format, and load it into your target systems. 


## Glue vs Kinesis
* Kinesis is primarily for real-time streaming data ingestion, processing, and analysis, while AWS Glue is a managed ETL (Extract, Transform, Load) service for preparing data for analysis, including batch and streaming workflows.
