## MAC address:
* Short for Media Access Control address, is a unique identifier assigned to a network interface card (NIC) by the manufacturer. It serves as the device's physical address on a local network, ensuring that data packets are sent to the correct device. 

## Registers
* Small, high-speed storage locations within the CPU (Central Processing Unit) used to hold data and instructions that the CPU is actively working with. They are the fastest type of memory in a computer system, providing very fast access compared to RAM or disk storage. 
* Types of registers:
    * Program Counter: Stores the memory address of the next instruction to be executed
    * Instruction Register (IR): Holds the current instruction being executed. 
    * Accumulator (AC): Stores the result of arithmetic or logical operations. 
    * Memory Address Register (MAR): Holds the address of the memory location being accessed. 
    * Memory Data Register: Holds the data being transferred between the CPU and memory.
